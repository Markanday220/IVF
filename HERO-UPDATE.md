## 🔧 Customization

To customize further, edit `src/components/Hero.jsx`:

### Change Background Image
```jsx
<img src="YOUR_IMAGE_URL" alt="Happy couple expecting" />
```

### Change Headline
```jsx
<h1>Your Custom Headline</h1>
```

### Change CTA Text
```jsx
<button>Your CTA Text</button>
```

### Change Colors
The magenta card uses: `from-pink-600 to-pink-700`
The CTA button uses: `bg-blue-600`

Adjust these in the component file as needed.
