## 🔧 Customization

### Update Headline
Edit line ~15 in `Hero.jsx`:
```jsx
<h1>Your Custom Headline</h1>
```

### Update Award Text
Edit line ~20:
```jsx
<p>Your Award or Tagline</p>
```

### Update CTA Button
Edit line ~24:
```jsx
<button>Your CTA Text</button>
```

### Update Trust Indicators
Edit the content in the trust indicators section (lines ~30-60)
