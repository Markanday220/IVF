# IVF Funnel Website

A premium, modern IVF funnel website built with React and Tailwind CSS, inspired by Oxxy healthcare funnel style.

## 🎨 Design Features

- Clean, trust-based, benefit-driven design
- Solid color text (no gradients)
- Soft backgrounds with white space
- Modern card-based layouts
- Fully mobile responsive
- High-conversion UI optimized for lead generation

## 🏗️ Structure (10 Sections)

1. **Hero Section** - High-impact introduction with emotional imagery and trust badges
2. **Problem Section** - Pain points presented in 4-card layout
3. **Solution Section** - Visual presentation of what you provide
4. **How It Works** - 4-step horizontal flow (Oxxy style)
5. **Trust Section** - Success stats and doctor profiles
6. **Services** - 6 service offerings with icons
7. **Pricing** - 3 transparent pricing tiers
8. **Testimonials** - Slider with real couple stories
9. **FAQ** - Expandable accordion
10. **Final CTA** - Strong closing with emotional imagery

## 🚀 Getting Started

### Installation

\`\`\`bash
cd ivf-funnel
npm install
\`\`\`

### Development

\`\`\`bash
npm start
\`\`\`

Opens at [http://localhost:3000](http://localhost:3000)

### Build for Production

\`\`\`bash
npm run build
\`\`\`

## 📝 Customization

1. Replace logo: Add your logo to `public/images/logo.png`
2. Update colors: Edit `tailwind.config.js`
3. Modify content: Edit component files in `src/components/`
4. Add real images: Replace Unsplash URLs with your images
